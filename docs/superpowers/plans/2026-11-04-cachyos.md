# CachyOS Implementation Plan

> Ejecutar por tareas, con prueba que falla antes de cada cambio funcional.

Goal: convertir PDF locales con seguridad e integración KDE.
Architecture: CLI existente, selección OCR por página, instalador KDE por usuario.
Tech Stack: Python, PyMuPDF, Tesseract, Tkinter, KDE .desktop.
Spec: ../specs/2026-11-04-cachyos-design.md

## Global Constraints
- Procesamiento local; ninguna API externa.
- Mantener compatibilidad de la API existente salvo opción explícita de salida.
- No sobrescribir el PDF original ni Markdown existentes sin opción explícita.

## Review Focus
- Destinos iguales al PDF original, enlaces simbólicos y colisiones en lotes.
- Stdout con imágenes exportadas o múltiples entradas: rechazar combinación.
- Escaneos después de las primeras tres páginas y PDF solo digitales sin OCR.
- Idiomas faltantes y páginas con imagen pequeña junto a poco texto.
- Rutas KDE con espacios, porcentajes y caracteres reservados.
